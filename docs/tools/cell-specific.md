# Cell-specific models

Cell-specific reduction is an optional extension to core THG construction. Use
transcript or activity evidence to reduce a model, preserve the source model,
and record exchange matching and gene-rule transformations. It does not turn a
generic reduction into a publication-specific cell model automatically.

See the [workflow API](../api/workflows.md) for
`reduce_model_by_activity`, exchange matching, and transcriptomics helpers.

Canonical API: [`reduce_model_by_activity`][thg_protocol.cell_specific.reduce_model_by_activity].
