# Contract: metabolic tasks

- **Legacy:** historical custom essential-task definitions under
  `memote_and_task_analysis/`.
- **Maintained:** no current replacement; ordinary MEMOTE is an external
  integration and is not task parity.
- **Inputs/defaults:** only an explicitly ported task definition, solver policy,
  model, and recorded expected results.
- **Result:** per-task feasibility, solver/version metadata, and failure reason.
- **Current status:** the task suite is Archived and has no replacement in this
  checkout. No parity or publication claim may infer task success from MEMOTE,
  connectivity, or formula-balance reports.
