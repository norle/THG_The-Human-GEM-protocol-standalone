# THG workflow runs

This directory is entirely generated by THG workflows. It contains resumable
run state, immutable configuration snapshots, manifests, logs, stage
artifacts, failed attempts, and final or exported artifacts.

A typical generated run retains this architecture:

```text
runs/<run-name>/
├── config.snapshot.json
├── manifest.json
├── logs/
├── artifacts/
│   └── <stage>/
│       └── attempt-0001/
├── failed/
└── .tmp/
```

Users should not manually reorganize files inside completed runs. Manifests,
checksums, stage dependencies, resume behavior, and upstream artifact
references depend on this structure.

Downstream workflows should reference upstream artifacts through the existing
`run_dir` / `stage_id` / `role` artifact-reference mechanism. Do not manually
locate files inside `artifacts/.../attempt-NNNN/`; the manifest is the stable
interface for those references.

Workflow-specific directories such as `beta1/`, `beta2/`,
`human-database/`, `final-thg/`, and `validation/` are created when workflows
execute and are intentionally not committed to Git.

`logs/run.log` preserves the workflow messages shown by verbose console runs.
